📚 Book Collection Manager Using DSA (Java)

A simple and efficient Book Collection Manager developed using Java and Data Structures & Algorithms (DSA). This project helps users organize, manage, search, update, and delete book records easily.

🚀 Project Overview

The Book Collection Manager is a Java-based application designed to manage book records in an organized way. It demonstrates the practical implementation of Data Structures and Algorithms through common book management operations.

✨ Features

- ➕ Add new books
- 📖 View all available books
- 🔍 Search books by ID
- ✏️ Update book details
- 🗑️ Delete book records
- 🔃 Sort books by title or ID
- 📚 Manage book collections efficiently

🛠️ Technologies Used

- Programming Language: Java
- Concept: Data Structures & Algorithms
- Data Structure: ArrayList
- Algorithm: Linear Search
- IDE: VS Code / IntelliJ IDEA / Eclipse

🧠 DSA Concepts

This project demonstrates:

- ArrayList – Dynamic storage of book records.
- Searching – Finding books using their unique ID.
- Sorting – Organizing books by title or ID.
- Classes and Objects – Representing book records.

⚙️ How to Run the Project

Step 1: Clone the repository.

git clone YOUR_REPOSITORY_URL

Step 2: Open the project in VS Code or any Java IDE.

Step 3: Compile the Java files.

javac src/*.java

Step 4: Run the main class.

java -cp src Main
